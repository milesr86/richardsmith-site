# Built values read back from the live page: 16 October 2026

The style guide (v0.1, register item 10) says: once the site is built, re-read
the type, colour and spacing from the page, note any drift, and supersede the
draft. This is that readback: computed styles measured in headless Chromium
(light theme, 1280px and 390px wide) against the guide's tables.

## Type: 15 of 16 match exactly

Wordmark, nav link, H1 (52/54, 36/40 below 640px), H2 (30/36, 26/32), year
marker, H3 / item title, lede, body, meta, caption, tag and footer all match the
guide's family, weight, size, line height, tracking, case and colour.

One apparent difference, intentional: the eyebrow inside the yellow book block
is ink, not muted. The guide says text on the sun block is always ink.

## Genuine differences from guide v0.1

1. **Measure.** The guide asks for 62-70 characters per line and also a 720px
   column. At 18px Newsreader the column holds about 93-99 characters. The
   column width was kept (it is also what the proposal promised); short
   paragraphs (the proposal's voice rule) keep it readable. Open decision.
2. **Tag padding** is 3px 10px (the guide is silent; 2px gave a 22px-tall
   target, under the 24px WCAG 2.2 minimum).
3. **Publication titles** are 18/28 regular, in quotes, not the 21/28 semibold
   "item title". This is the proposal's presentation.
4. **Sun block in dark** is ochre `#BC862A`, not `#D9A040`; ink text on it is a
   fixed `--on-sun` token (the guide's own name for it), because the theme's ink turns pale in dark mode.
5. **Dark palette** (paper `#110F0D`, red `#EE6657`, raised `#2C2723`, rule `#403931`, blue `#3DA9BF`, ink `#E6DFD0`, muted
   `#A8A090`) replaces the guide's first dark values. All text pairings are at
   least 4.5:1; the lowest is red on paper-raised at 4.7:1.
